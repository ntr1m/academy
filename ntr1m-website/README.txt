NTR1M Skate Academy website redesign

Preview locally:
1. Open index.html directly in a browser, or
2. Run: python -m http.server 8000
   then visit http://localhost:8000

Deployment:
This is a static website designed for GitHub Pages. Upload the full contents of this folder to the repository root (or configured Pages directory).

Notes:

- Hero video is an optimized copy of the supplied skating footage.
- Replace or edit content directly in the HTML files.
